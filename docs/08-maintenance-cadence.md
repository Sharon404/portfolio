# Maintenance Cadence

## Monthly
1. Add newly completed design and engineering projects.
2. Refresh featured projects on Home.
3. Validate all outbound links and media assets.
4. Review analytics for recruiter behavior trends.

## Quarterly
1. Archive low-relevance projects.
2. Rewrite case studies with updated outcomes.
3. Re-run performance and accessibility audits.
4. Review SEO metadata and social preview accuracy.

## Before Job Applications
1. Ensure top 3 projects align with target role.
2. Confirm CV and contact details are current.
3. Verify GitHub repositories are public and README quality is high.
